<Section title="System problem">

A session has people, rooms and time. Check-ins arrive from a web app, a rotating QR code at a kiosk and a face-recognition worker. Any of them can fail silently. If silence is recorded as absence, one broken camera marks a whole room absent. The system has to say what it saw, what it inferred, and what it could not see.

</Section>

<Section title="Six presence states">

<PresenceStates />

<Ev id="sa-rules">In this precedence order, every millisecond of a session gets exactly one state.</Ev> Attendance is present time divided by *observable* time; below 80% camera coverage the result is INCONCLUSIVE, not a verdict.

</Section>

<Section title="Signed worker">

```text
signature = HMAC-SHA256(device_key,
            method ‖ path ‖ SHA-256(body) ‖ timestamp ‖ nonce)
-- a stale timestamp or a reused nonce is rejected: no replay
```

Shown as a formula, not source code. The repository is private.

</Section>

<Section title="Presence engine and differential testing">

<Ev id="sa-diff">The engine is tested against a deliberately naive model</Ev>: interval arithmetic in integer milliseconds on one side, a slow model that decides each millisecond on its own on the other. Both get the same generated intervals; any disagreement fails. That proves the two agree, not that either matches a real classroom.

</Section>
