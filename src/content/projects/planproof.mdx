<Section title="Problem">

Ask an assistant to speed up a query and it will usually answer with an index or a rewrite, and an explanation of why it is faster. The explanation is not a measurement, and the rewrite may not even return the same rows. PlanProof treats the suggestion as a candidate and checks it against the query you already trust.

```sql
-- "NOT IN is supposed to be bad. Rewrite this for me."
SELECT c.id, c.name FROM customers c
WHERE c.id NOT IN (SELECT customer_id FROM orders WHERE status = 'pending')
```

</Section>

<Section title="Why the obvious checks fail">

| Obvious check | Why it is not enough |
| --- | --- |
| Read the assistant’s explanation | It describes a plan; it does not run one. |
| Time both queries | Browser clocks are coarse. <Ev id="pp-distorted">Version 1.0.0 reported distorted speed-ups</Ev> until timing was isolated and reported as a lower bound. |
| Compare results on your data | Ordinary data hides edge cases. In the NULL trap below, both queries return 9,414 rows until one value is unknown. |

</Section>

<Section title="Decisions">

| Chosen | Rejected | Why |
| --- | --- | --- |
| Structural checks before timing | Timing first | A faster wrong answer is still wrong. |
| Multiset comparison of canonical rows | Set comparison | Sets hide duplicated rows. |
| Index trials rolled back | Keep the index | Each candidate starts from the same database. |
| A worker with a watchdog | Run on the page | A runaway query cannot freeze the tab. |
| 1.5× plus cost or rows read | Any measured speed-up | Noise on coarse clocks looks like a win. |

</Section>

<Section title="What would change next">

<Ev id="pp-limits">The project documents where it stops</Ev>, and what would move each limit:

- **Rate limiting** is per serverless instance, in memory. A shared store such as Redis would make it global, at the cost of a new dependency.
- **Datasets** are bounded by browser memory: up to 10,000 rows per parent table and 100,000 per child table; result sets above 200,000 rows are not compared.
- **AI suggestions** share one free-tier provider quota across all visitors.
