<Section title="Provenance">

Every row carries where it came from. Three provenance classes are kept apart by key and constraint, so a transcribed value can never be mistaken for a measured one.

</Section>

<Section title="Idempotent ingestion">

<Ev id="rdp-idem">Each file is stored once, under its name and SHA-256.</Ev> Running the pipeline again over the same files: 14 seen, 0 landed.

</Section>

<Section title="Reconciliation is the exit condition">

The load is not finished until SQL recomputation equals the recorded results. Each check is labelled before it runs: exact, within tolerance, or not comparable. <Ev id="rdp-recon">16 of 16 checks pass on the reproducible path.</Ev> <Ev id="rdp-tests">The platform has its own test suite.</Ev>

</Section>
