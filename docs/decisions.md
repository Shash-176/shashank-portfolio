# Implementation decisions

Design decisions live in the planning documents. These are the ones made while building.

| Date        | Decision                                                                                                              | Why                                                                                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 22 Nov 2026 | Astro 7, vanilla CSS tokens, vanilla TypeScript islands                                                               | See `architecture.md`. Initial JS on the home page is 2.7 KB gzip                                                                                            |
| 22 Nov 2026 | Vercel primary, Cloudflare Pages backup                                                                               | Existing account; plain static output                                                                                                                        |
| 22 Nov 2026 | Evidence numbered after render, in document order                                                                     | Astro renders slots concurrently, so render-order numbering was non-deterministic (found in testing)                                                         |
| 22 Nov 2026 | Diagrams rest **separated**, with an Assemble control; print shows them separated with the text list                  | The freeze said "assembled at rest". In the browser, the separated state is readable without interaction and without JavaScript; assembled is one click away |
| 22 Nov 2026 | Hero notes always visible at ≥ 1100 px; folded on smaller screens until tapped or the lens is on                      | Keeps the phone's first screen short                                                                                                                         |
| 22 Nov 2026 | Live PlanProof mode deferred to v1.1; the exhibit links to the live tool                                              | 15 MB engine and cross-origin isolation for something the real tool already does                                                                             |
| 22 Nov 2026 | Presence timeline uses the project's demo policy (75% required, 80% minimum coverage) from `backend/app/portfolio.py` | Real rules, synthetic data                                                                                                                                   |
| 22 Nov 2026 | Visual baselines not committed                                                                                        | 7.7 MB and machine-specific                                                                                                                                  |
| 22 Nov 2026 | No syntax highlighting in code blocks                                                                                 | Default themes clash with the palette; code is short                                                                                                         |
| 22 Nov 2026 | Avatar pause control omitted in v1                                                                                    | v1 stills never move on their own; the 3D version must add one                                                                                               |
